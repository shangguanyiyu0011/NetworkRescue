离屏检查覆盖三阶段真实延迟图、少于 3 个成功样本不计算统计、负增量、失败不造零、DNS 有效回复与 NXDOMAIN/NODATA/超时的区别、未尝试留空、Wi-Fi 真实零信号与不可读、真实历史窗口、主题/语言输入隔离及大消息边界。

真实跨进程集成验证：最终应用控制器在隔离存储中自动运行 `127.0.0.1` ICMP，6/6 成功，保存 Completed、6 个目标样本、2 个实际 Wi-Fi 快照。第二进程读取同 ID，`wifiSupported=true`、总数 2，历史载入及事件回放通过。另用 1.2 只读载入上轮 1.1 生成的真实 DPAPI 文件，保留 Completed、3 个样本，无 Wi-Fi 数据，读前读后文件哈希一致。

容量回归使用合法的 4×300 个目标样本、500 个长配置事件、720×8 个 Wi-Fi 接口及需要 JSON 转义的网卡名。已将发送端/接收端统一为有界 8 MiB，完整组合可读回；恰好 8 MiB 接受、超出 1 字符拒绝，未截断原始证据。网络报文与存储大小限制没有放宽。

本机文件符号链接测试因权限不足跳过，目录 junction 测试通过。专项和离屏数据不代表公网连接质量、实际路由器故障或真实运营商问题；没有以 fixture 冒充完整实窗交互。

真实 1.2 窗口已观察到版本、监测页 Wi-Fi 稳定性空态、测速页三阶段负载延迟空态及 DNS 稳定性入口。实窗检查发现并补齐了一项缺失的提示文案；新增功能的 22 个动态阶段/状态提示及所有静态 U/T 字面量键，十语均覆盖且非空，每语 736 键。没有启动公共测速或更改用户网络配置，也未操作此前受用户输入保护的窗口。

Windows PowerShell 5 与当前 pwsh 的 x64/x86 四种打包组合均通过：每包 29 个允许条目、零反斜线 ZIP 路径、版本 1.2.0.0、对应 PE 架构及逐文件哈希匹配。最终补文案后两架构构建目录的十语文件均与源码逐文件哈希一致。补文案后的实窗复验遇到其他用户窗口在前景，未抢占焦点；文案以十语完整性与离屏验证为依据，不冒称实窗复验已通过。正式发行包的校验值以 GitHub 同一提交构建及发行资产中的 SHA256SUMS 为准。

## 边界

- 负载延迟至少 3 个成功样本才提供 median/P95，500ms 为目标采样周期，超时/取消不制造成功点；所有结果只对应本次目标、代理路径与测试时段。
- Wi-Fi 只保留最近 720 个约 5 秒快照，较长会话可能缺少早期无线证据；完整计数与截断状态明确展示。信号、协商速率和掉线时间上的接近不证明故障因果。
- DNS 比例以完成轮为分母：至少一个 A/AAAA 有效回复算响应轮、至少一个有地址算解析成功轮、任一个超时算含超时轮，这些指标不互斥。NXDOMAIN/NODATA 与没有响应不同，不自动排序切换 DNS。
- 历史 schema1 保持可读，不自动重写或伪造旧版本未采集的 Wi-Fi；新记录为 schema2，保留现有 DPAPI、20 条/64MiB、单文件 16MiB、严格路径及损坏保护。
- 本机 x86 进程测试不等同纯 32 位 Windows OS 验收。实窗操作遇到用户输入保护即停止，不绕过保护或更改全局网络设置。

正式发布必须通过 GitHub Actions 同一提交的双架构检查和 ZIP 白名单/哈希校验；发行后回读标签提交、公开状态与下载资产。

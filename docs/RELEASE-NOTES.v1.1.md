# 1.1.0 · 断网追踪与定位增强

- **监测历史与跨启动回放**：手动开始监测后，自动保存本机会话；每 15 秒及结束、正常关闭时保存加密检查点。保留每目标最多 3,600 个真实样本、最近 500 个事件与完整事件总数；历史回放可查看早于图表最后 300 点的实际样本。支持删除、清空可读记录、脱敏预览后导出。最多 20 条、总文件 64 MiB，超量淘汰最旧可读会话；损坏文件保留并提示。
- **IPv4 / IPv6 独立网页验证**：使用各自解析出的地址实际探测 HTTP(S)，保留原域名 Host、TLS SNI 与平台证书验证。每族最多 2 个地址、共同 3 秒时限；无对应地址时显示不适用，部分地址未响应不等于整个协议故障。沿用 TLS 1.2，不自动更改网络配置。
- **公共网络认证引导**：当现有诊断证据提示疑似门户时，用户可确认后在系统浏览器打开 Windows 认证触发页，认证后重新检测；该入口不保证是实际门户地址，不自动打开或代填账号。

支持 Windows 10/11 x64、Windows 10 x86，系统 .NET Framework 4.8。下载便携 ZIP 后完整解压运行。修复范围、默认权限及已有数据兼容性保持不变。

运行中意外退出时，历史显示最后检查点“已中断”，最多约 15 秒的新样本可能尚未保存。ICMP 无响应不证明整机断网；历史中的配置变化不证明故障因果。文件使用当前 Windows 用户的 DPAPI 加密，分享仍需检查脱敏预览。

本版本构建及验证范围见 [验证记录](RELEASE-READINESS.v1.1.md)。同版本源码由本发行的 `v1.1.0` 标签提供；自有代码 GPL-3.0-only，第三方说明见仓库。

# 1.2.0 · 网络质量与稳定性增强

- **负载延迟检测**：测速分别记录空闲、下载及上传阶段的真实 HTTP 延迟样本，展示中位数、P95、成功/失败计数及相对空闲中位数的变化。单个独立连接组探针约每 500ms 采样，成功样本少于 3 个时统计留空；保留 30 秒与正文总流量上限。结果仅描述当前节点路径，不能直接认定路由器或运营商故障。
- **Wi-Fi 稳定性时间线**：手动监测期间约每 5 秒只读当前无线接口的信号质量和协商链路速率，最多保留最近 720 个快照及完整观测总数。历史事件回放关联前后 10 秒内的真实无线证据；缺失明确显示。区分无无线接口、未连接、权限不足和部分可读；不扫描附近网络，不保存 SSID/BSSID/网卡名称，不更改权限、服务或信道。
- **DNS 稳定性评估**：对指定域名和 1–4 个 DNS 服务器执行 3–10 轮查询，默认 5 轮、最长 60 秒。分别展示响应、解析出地址和超时的轮次比例及成功轮耗时分布。每轮同时包含 A 与 AAAA，耗时不是单查询 RTT；缓存、域名和正常负载均衡会影响结果，不自动修改系统 DNS。

监测历史保存为 schema2，兼容只读载入 1.1 的 schema1；旧记录明确标示未采集 Wi-Fi，不自动重写旧文件。仍然需要手动开始监测，不安装后台服务。原有四种受证据约束的修复范围不变。

提供 Windows x64/x86 便携 ZIP，系统要求 .NET Framework 4.8。完整验证范围见 [验证记录](RELEASE-READINESS.v1.2.md)，同版本源码由发行标签 `v1.2.0` 提供。

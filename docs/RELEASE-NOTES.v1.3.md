# 1.3.0 · 托盘监测、观测时段与离线报告

- **手动托盘监测与通知**：托盘模式默认关闭。明确启用并手动开始监测后，可隐藏或关闭窗口，在托盘继续当前会话；从托盘可显示窗口、停止监测、静音或彻底退出。彻底退出会停止并保存，不设置开机自启、不安装服务，也不自行开始监测。连续 3 次无响应后通知；只有已实际通知无响应的周期，连续 2 次响应后才配对提示恢复。重复无响应每目标冷却 60 秒，全会话通知限流 10 秒；静音或冷却抑制的转换不积压。大采样缺口、挂起或恢复会重置连续计数，不用未观测时段凑通知阈值。现有采样次数、保存周期和历史容量限制不变。
- **按目标的观测无响应时段摘要**：分别列出无响应次数、首次与末次失败观测、恢复观测、未闭合时段和采样缺口。观测跨度是末次减首次无响应时间，不是估计的整机停网时间。HTTP 403 等有效响应不算无响应，缺口不算故障；附近配置和 Wi-Fi 仅为同时段证据，不推断因果。界面最多各预览 200 个时段和缺口，同时显示总数和截断，可定位仍保留的原时间线事件。
- **单文件离线 HTML 监测报告**：先将 typed 记录投影为匿名会话别名，排除主机、IP、接口身份、网卡/网络名称、路径和配置原值，再生成摘要、真实曲线和时间线。完整 HTML 先在内存构造，预览仅为同一匿名数据的可读摘要，并非渲染整页；确认后才选择本地保存位置。报告无 JavaScript 或外部资源，不自动打开或上传，完整绘制已保存样本而不降采样；单文件上限 8 MiB，超限明确提示，不静默删点。所有报告时间为 UTC，分享前仍须检查。

跨休眠边界完成的请求从有效观测中排除，不将其计为成功或无响应。界面、最终结果、历史与文本导出的统计，从保留的原始样本深复制投影后重新计算；schema2 原始计数保持兼容，不为展示改写旧文件。缺失观测保留为缺口，不能据此推断故障。

保留 1.2 的负载延迟、Wi-Fi 时间线、DNS 稳定性及此前功能。schema1/schema2 旧监测记录继续可读，载入或回放不自动改写。四种受证据约束的修复范围不变。

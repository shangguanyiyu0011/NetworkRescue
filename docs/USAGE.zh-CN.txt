断网急救箱 Network Rescue 1.3.0 使用说明
开发与维护：上官一羽。自有代码 GPL-3.0-only，见包内 LICENSE；对应源码：https://github.com/shangguanyiyu0011/NetworkRescue/tree/v1.3.0

运行与下载
从官方仓库 https://github.com/shangguanyiyu0011/NetworkRescue/releases/tag/v1.3.0 获取 NetworkRescue-v1.3.0-win-x64.zip 或 NetworkRescue-v1.3.0-win-x86.zip，完整解压到可写本地目录后打开 NetworkRescue.exe，保留语言、图标和说明文件。
基线：Windows 10 22H2 x86/x64、Windows 11 x64，系统 .NET Framework 4.8 或更高。Windows 11 无 x86 版；纯 32 位 OS 未实测。无需另装 WebView2、.NET SDK、Node.js 或 Python。正式 EXE 未作应用数字签名。
旧 NetworkRescue 标识及 %LOCALAPPDATA%\NetworkRescue\ 路径保持兼容，不会因中文改名迁移/清空设置或备份。

新手诊断与修复
1. 点击“开始诊断”，等待八项检查：网络硬件、连接配置、DHCP 服务、DNS、HOSTS、系统代理/PAC、LSP/Winsock、HTTP 联网。只读诊断可停止。
2. 查看状态、证据、置信度与下一步。没有建议不等于网络正常，也可能是证据不足。
3. 如有建议，核对影响并选择项目；推荐项默认全选，AutoDns 不默认选择。未扫描、无建议、未选或忙碌时修复入口不可用。
4. 点击“一键修复”并确认。程序先复查与备份，执行后重新诊断；不要把操作完成等同网络已恢复。

四种修复与权限
FlushDns：清缓存，不改 DNS 服务器，旧缓存不能恢复。
RenewDhcp：仅符合条件的 DHCP 网卡，连接可能中断，租约不能精确回滚。
AutoDns：替换自定义 IPv4 DNS 为自动，默认不选；原配置可从备份恢复。
DisableProxy：关闭当前用户手动代理开关，保留地址、不改 PAC；原配置可恢复。
不自动清空 HOSTS、重置 Winsock/WinHTTP、删除路由、卸载网卡或重启 Windows。
诊断和测速普通权限运行；除 DisableProxy 外，修复按需同账户 UAC 后重新诊断/选择，不自动继续写入，另一个管理员 SID 会被拒绝。
逐项结果可能为部分完成、需重启或待确认。异常退出后的恢复入口由用户选择，不自动回滚；还原异常保留已保存备份与步骤。

代理/VPN 与 Wi-Fi
只有手动代理全部为失效回环、端口全部失败、无 PAC/WPAD、代理 HTTP 失败而直连实际成功等前提同时成立，才建议关闭残留代理。正常代理、公司代理、自定义 DNS 应结合用途判断。
VPN/Wi-Fi 专项只读 PAC/WPAD、WinHTTP、DNS、路由、虚拟网卡与当前 Wi-Fi。不下载或执行 PAC，不登录认证门户，不读取 Wi-Fi 历史密码。信号/关联速率不是宽带速度。
网关不回 ICMP 不能证明断网；多公网端点失败不能确认运营商责任。专项的通过、未知或不支持入口保持禁用，不扩大修复能力。

高级工具与活动连接
高级模式可看分组证据和折叠原始日志，当前项修复与下方批量选择独立。
Ping、DNS、Trace、TCP 使用真实样本；目标域名/IP，TCP 端口 1–65535。DNS 对比向 1–4 个显式服务器查询 A/AAAA，UDP 有界、截断回退 TCP，不改系统 DNS；地域/CDN/缓存差异不是污染证据。
网卡卡片是刷新快照。活动 TCP 关联 PID/程序名，可搜索地址、端口、PID、名称并按状态筛选，仅覆盖最多 512 条已读取行。进程信息为非原子快照，可能退出、不可读或 PID 复用，不提权、不结束程序。
网站排查可输入域名或 HTTP(S) 网址，只请求显示的 origin 根路径，丢弃路径/query/fragment，拒绝凭据及非法端口。分别强制 IPv4/IPv6 HTTP(S) 验证，每族最多尝试 2 个已解析地址，共限时 3 秒，保留原域名和默认 TLS 验证、绕过系统 HTTP 代理。无 AAAA 时 IPv6 不适用，不是 0 ms；局部未确认不证明整个协议不可用，不自动禁用协议。
疑似网络门户仅提供手动入口：确认后在系统浏览器打开 Windows 网络认证触发页，网络可能重定向。它不是已确认的实际门户，不自动登录、不提交凭据。完成认证后点击重新诊断。

持续监测与常用设置
1. 输入 1–4 个域名/IP（不填 URL 路径），分别选 HTTPS/ICMP 与 HTTPS 系统代理/忽略代理路径。
2. 设置统一目标间隔 1–10 秒及每目标最多 3,600 次；全部目标验证后才发包，请求耗时会拉长实际间隔。
3. 开始后各目标独立统计，最多保存每目标 3600 个真实样本，各曲线显示最近 300 点；可停止，已有观测保留。编辑输入不改变旧会话图表，下一次确认开始才替换。
4. 可展开默认收起的“常用监测设置（可选）”保存上方完整参数，最多 20 方案；下次选择只填参数，再自行开始，不会自动发包。
“添加网关”只使用已读取的配置网关，不证明当前有效路由。ICMP 不跟随 HTTP 代理，忽略代理不等于绕过 VPN。
HTTPS 只读头，TLS 校验、3 秒取消、32 KiB 头部上限，不跟随跳转、不发默认/代理凭据。任何状态都代表应答，不等于网页可用；407 提示代理认证，耗时含 DNS/TLS/代理。

变化时间线与异常回放
运行中约每 2 秒只读采集去秘密后的代理/PAC、DNS/IP、配置网关及网卡状态，并记录目标无回应/恢复。读取失败或不完整不当删除，变化不证明因果。
时间线最多保留最近 500 事件并显示完整总数/截断。长值最多三行，tooltip/复制保留完整值；停止后可先脱敏预览，再选本地保存位置。
选择事件联动真实缓存：目标事件前后一个采样间隔（至少 2 秒）取最近实际点，配置变化前后 10 秒，并显示同时间其他目标。没有真实样本时明确缺失，不补造点；曲线只显示最近 300 点，但历史最多保留每目标 3600 个真实样本。
手动开始后自动使用当前用户 DPAPI 本地加密保存，每 15 秒及监测结束/应用退出时保存；最多 20 条且总计 64 MiB，不上传、不安装后台服务。监测历史可刷新、载入跨启动回放、删除所选或清空；载入不发起网络检测。删除/清空需确认，损坏记录不覆盖不删除，清空只删除可读记录。
Interrupted 表示意外中断，仅恢复最后保存的检查点，最多 15 秒样本可能未保存。加密不等于匿名化，IP/域名仍需在分享前检查。

Wi-Fi 稳定性时间线
手动开始持续监测后，约每 5 秒只读采集 WLAN 当前连接的信号、接收/发送链路速率和 UTC 时间；最多 720 个采集快照，每个快照最多 8 个接口。
在时间线中与目标无应答事件联查。没有观测、读取失败或未连接不等于信号为 0，时间接近也不证明无线连接造成故障。
不存 SSID、BSSID 或网卡名称，不更改 WLAN 权限、服务或信道。监测历史使用 schema 2，继续读取 1.1 schema 1；旧记录无 Wi-Fi 数据时不补造。仍只在手动监测期间采集；手动启用托盘模式后，可在隐藏窗口时继续当前监测。

托盘监测与通知
1. 默认不启用托盘。先明确启用托盘模式，再手动开始监测；设置本身不发包、不自启、不安装服务。
2. 隐藏到托盘或关闭窗口可继续当前监测。要停止，可从托盘重新显示窗口后停止；“彻底退出应用”会停止并保存。隐藏不是退出。
3. 连续 3 次无响应后通知；只有已实际通知无响应的周期，连续 2 次响应后才配对提示恢复。重复无响应每目标冷却 60 秒，全会话通知限流 10 秒，可静音；被抑制的转换不积压。通知只描述目标观测，不代表整机断网。
采样缺口大于 3 倍间隔与 10 秒两者的较大值，或系统挂起/恢复后，连续计数重置为未知，不用未观测时段凑阈值。会话结束会提示完成、停止或未完成。
监测仍按既有次数结束，最多每目标 3600 样本；历史容量、15 秒检查点等限制不变，托盘不是无限期后台服务。

观测无响应时段摘要
监测结束或载入历史后，按目标查看次数、起止观测、最后失败、恢复及未闭合区间，采样缺口单独列出。时长是首末失败之间的已观测范围，不是整机实际停网时间。
HTTP 403 等有效应答不算无响应；缺口不计故障，时间附近的配置/Wi-Fi 变化不证明原因。界面最多显示 200 个时段和 200 个缺口，并显示总数与截断。可定位保留的原时间线事件，缺失不会补造。

单文件离线 HTML 监测报告
选择当前已结束的会话或载入历史，点击导出离线 HTML。程序先把 typed 数据转成匿名别名再生成摘要、真实曲线与时间线，先在内存构造完整 HTML，再显示同一匿名数据的可读摘要及脱敏范围。预览不渲染整个 HTML 页面；确认后才打开文件选择器选择本地保存位置。
报告完整绘制已保存样本而不降采样，单文件上限 8 MiB，超限提示、不静默删点；不含 JavaScript 或外部资源，不自动打开、不上传。分享前请再次检查内容，匿名别名不能保证所有环境特征都无法辨认。
schema 1/2 旧历史均可读取，读取和回放不改写旧文件；没有采集过的 Wi-Fi 或样本无法补出。

DNS 稳定性
1. 明确填写一个域名及 1–4 个 DNS 服务器 IP。
2. 设置 3–10 轮，默认 5 轮，手动开始；总时限 60 秒。
3. 分别看响应率、解析结果、超时率与真实样本。每轮时延是 A+AAAA 查询的总耗时，不是单个查询的往返时间。
结果受缓存影响且只针对所选域名；单轮最快不足以推荐服务器。工具不自动更改 DNS，停止或超时不补造后续结果。

健康快照
1. 完成最近 5 分钟内成功的联网诊断；保存前配置须仍相同且读取完整，否则重新诊断。
2. 正常诊断卡点“保存为健康快照”直接按本地日期时间命名，同秒加序号并确认，不跳设置；设置中的健康快照卡保留手动命名。
3. 最多 20 个，名称最长 64 字符；选择后只比较代理脱敏 authority、DNS/IP、配置网关与网卡状态。变化不等于故障，不自动还原。
保存前私密 Fingerprint 只在内存比较；跨启动不保存/比较 PAC 私密路径或凭据。对比预览可能截断，会显示预览数/总数，不能把截断当成无差异。

报告、历史与还原
导出报告先在应用中查看脱敏预览，再选本地保存；不自动上传。固定规则不能覆盖全部自由文本，分享前仍须检查；原始界面、加密历史不代表匿名化。
修复/还原后显示配置观察差异和 HTTP 复检，差异不证明因果。历史在设置内，最多保留 100 条，UI 预览 20 条，导出全部仍保留记录；读取损坏会提示，不静默覆盖。
还原只接受本工具备份目录内经校验的 .nrb，并先备份当前配置；也可还原上次可用备份。只恢复涉及的 DNS/代理，不恢复旧缓存/租约、不转静态 IP；仍需确认及按需同账户 UAC。

宽带测速
访问 Cloudflare 公开节点，单连接下载最多 48 MiB、上传 24 MiB、正文总计不超过 73 MiB，最长 30 秒，协议开销另计；上传只用合成数据。
默认请求级忽略系统代理，可选系统代理/PAC，两者仍可能经 VPN。曲线与最终值均是完整成功样本累计有效字节/阶段实际耗时，下载/上传使用各自阶段时间。
靠近真实节点查看时间与阶段平均速度，不插值制造点。停止时未完成最终指标为空，不拿进度替代；HTTP 往返不是 ICMP Ping。新增空闲、下载、上传三个阶段的真实延迟样本，分别显示中位数、p95 与相对空闲基线的增量；样本不足显示未确认，不补成 0。结果仅描述到该测试节点的路径，不保证 ISP 接入带宽，也不能确认路由器造成延迟。

外观、语言、帮助与反馈
暖昼/静夜即时切换保存，保留页面、输入、报告和曲线；应用弹窗同步主题，UAC/系统选择器随系统。
十语界面切换清除旧动态结果，重新运行获得当前语言报告；系统名称/错误可能保留原文。使用帮助按八类主题分步骤呈现，并保留五个离线自救主题，不自动执行步骤。

版本与更新默认配置官方 GitHub 仓库 shangguanyiyu0011/NetworkRescue，无需手填。旧空设置自动补全，非空自定义值保留。仍需点击检查，只打开同仓库可信 HTTPS 发布页并由用户手动下载；不自动联网检查或安装，地址校验不等于下载签名验证。

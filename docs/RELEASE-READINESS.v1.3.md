日期：2026-10-28。产品版本 1.3.0，程序集/文件版本 1.3.0.0。

## 验证范围

## 实际 NotifyIcon 与隔离控制器集成

真实 Windows NotifyIcon 的隔离实例已经验证：默认不显示图标，启用后 `Visible=true`；实际菜单项通过 `PerformClick` 触发回调，静音、停止、退出及 `Dispose` 移除图标均通过。此项使用系统 NotifyIcon 与实际菜单对象，但不是人工双击图标或系统通知可见性的验收。

独立 WPF Dispatcher 集成使用始终隐藏、从不激活的窗口，实际 Controller 手动监测 `127.0.0.1`，3/3 响应。窗口隐藏期间会话正常结束，隔离历史保存为 Completed、3 个样本和 1 个 Wi-Fi 快照；托盘转为 idle，`RequestExit` 后移除图标。该证据属于隐藏窗口下的控制器/托盘集成，不冒称实际用户窗口显示或人工关闭交互已经验收。

## 统计与休眠边界修正

跨休眠边界完成的请求从有效观测中排除，不计入响应或无响应。显示统计从保留的原始数据深复制投影后重新计算，最终结果、历史载入和文本导出使用一致的观测口径；schema2 原始计数保持兼容，不因展示重算而改写历史原件。

上述修正已经纳入 411 项 Controller 定向检查通过，覆盖统计投影与最终/历史/文本口径，以及零 attempt 时保留 Resolve 证据、全部 stale 时显示未知的边界。UI 追加曲线不跨采样缺口、Sent 为 0 时显示“—”的定向回归已通过，并包含在最终 NativeWindow 1346 项及双架构完整构建中。

Replay 的无响应显示统一为“无响应观测跨度（首末失败样本）”：由摘要区间的首末失败观测计算，不从时间线事件延伸到会话结束。未闭合只表示未观测到闭合恢复，不能认定此后持续断网；没有可用样本时跨度为空，不补成 0 或估计时长。最终、历史回放与文本导出采用相同口径。

Controller 追加回归后的最终定向计数为 411 项通过，替代此前的 404 项阶段计数；它不是完整 23 套或双架构构建总数。

## 边界

- 托盘默认关闭，仅在用户明确启用后继续手动开始的当前监测。无开机自启或后台服务，彻底退出停止并保存；既有每目标最多 3600 样本、15 秒检查点、20 条/64 MiB 历史上限保持。
- 无响应通知需连续 3 次实际观测；恢复通知只与已实际发出的无响应通知配对，并需连续 2 次响应。静音或冷却抑制的转换不排队补发。大缺口或挂起/恢复重置连续性为未知。
- 时段只描述对应目标的保留观测。HTTP 403 等有效响应不是无响应；采样缺口不能算作故障，未闭合不等于持续至当前的已确认断网。附近配置或 Wi-Fi 只说明时间关系，不证明因果。
- UI 各预览最多 200 个时段和缺口，显示总数及截断。HTML 根据完整保留证据生成；缺失或未采集的数据不能恢复。报告最大 8 MiB，超限应明确失败，不静默删点。
- schema1/schema2 旧历史保持可读，不为回放或显示统计重算而自动改写。旧记录未采集 Wi-Fi 或采集关闭时，不伪造无线观测或据此判定连接状态。
- 匿名别名不等于报告绝对无法关联到环境。报告不含脚本或外部资源、不自动打开或上传，分享前仍须检查。
- 本机 x86 进程测试不等于纯 32 位 Windows OS 验收。离屏、fixture、离线浏览和打印验证不能替代真实网络故障修复或长稳；NotifyIcon 的 PerformClick 和隐藏窗口集成不等同人工托盘操作或系统通知可见性验收。

历史证据保留在 [1.2](RELEASE-READINESS.v1.2.md)、[1.1](RELEASE-READINESS.v1.1.md)及[1.0](RELEASE-READINESS.v1.md)，各自只绑定当时产物。旧截图仍为 1.0 历史图，不转作 1.3 实窗证据。正式发布需回读同版本标签、对应源码与实际发行资产；正式资产校验以同提交 CI 构建及发行资产 SHA256SUMS 为准。

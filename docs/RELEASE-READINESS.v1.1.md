# NetworkRescue 1.1.0 验证记录

验证日期：2026-10-28。产品版本 1.1.0，程序集/文件版本 1.1.0.0。

## 变更范围

- 新增监测历史加密持久化、完整会话样本保存、跨启动事件回放与历史导出。
- 新增 IPv4/IPv6 独立 HTTP(S) 探针，保持 Host、TLS SNI 和平台证书验证。
- 新增疑似门户的手动 Windows 认证触发入口与重新诊断操作。
- 十语界面文案、使用说明、版本及双架构构建发布同步更新；不增加网络修复动作。

## 已完成的专项检查

- MonitoringHistory：55 项断言，包括 DPAPI 往返、重启读取、Interrupted、14,400 个真实样本、20 条/64 MiB 保留清理、损坏隔离与目录 junction 拒绝。
- SiteDiagnostics：114 项断言，包括真实 IPv4/IPv6 loopback、真实 TLS ClientHello 的原域名 SNI、平台拒绝自签名证书、取消/截止/响应头边界，以及 HEAD 405/403/302 不误报无响应。
- PortalLogin：56 项断言，包括已知系统联网标记、门户疑似证据、普通重定向不误触发、固定 HTTP(S) 入口校验及无联网/浏览器副作用。
- 十语 locale：每语 671 个键、键集一致、有效 UTF-8 JSON。

`publish.ps1` 校验程序集版本、PE 架构、ZIP 文件允许清单与逐项哈希；不把本机数据、修复备份或监测历史打入便携包。GitHub Actions 对同一提交再执行双架构 18 套检查，通过后生成正式 ZIP 和 SHA-256 文件。

## 验证边界

- Windows 本机 x86 进程测试不等于纯 32 位 Windows 系统验收。
- 文件 symlink 测试在本机因系统权限不足跳过；目录 junction 测试实际通过。
- 未执行会改变用户网络设置的修复、未自动登录认证门户、未以历史 1.0 截图替代 1.1 证据。
- 历史保存故障应显示提示并允许监测/正常关闭继续；不覆盖损坏记录。正常关闭同步保存；意外终止最多约 15 秒的末尾样本可能未持久化。
- HTTP 状态只证明收到响应，ICMP 无响应不证明整机断网；单地址失败、配置变化均不证明整体协议故障或故障因果。

GitHub 发布时由同一源码提交分别构建两种架构，ZIP 的 SHA-256 在发布作业校验并作为发行资产提供；发布后回读标签、公开状态和资产。
